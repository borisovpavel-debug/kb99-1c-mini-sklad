# Мини-Склад

Учебная конфигурация на платформе 1С:Предприятие 8.3 по первым пяти главам книги
«1С:Предприятие 8.3. Практическое пособие разработчика».

## Что внутри

- Подсистема «Мини-Склад».
- Справочник «Товары».
- Справочник «Контрагенты» с ИНН, КПП и контактной информацией. При записи проверяется правильность ИНН, КПП, телефона и почты.
- Документы «Поступление» и «Реализация». В формах документов сумма пересчитывается автоматически.
- Регистр накопления «Остатки товаров». Поступление записывает в него приход, реализация записывает расход.

Выгрузка конфигурации лежит в папке `src/cf`.

## Как открыть

1. Создать новую пустую информационную базу.
2. Открыть её в режиме «Конфигуратор».
3. В меню «Конфигурация» выбрать «Загрузить конфигурацию из файлов» и указать папку `src/cf`.
4. Обновить конфигурацию базы данных клавишей F7.
5. Запустить «1С:Предприятие» клавишей F5 и открыть раздел «Мини-Склад».
